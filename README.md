# Trabajo-Final-POO

Sistema de taller mecanico desarrollado en Java como proyecto simple de POO.

## Ejecutar en VS Code

1. Abrir esta carpeta en VS Code.
2. Instalar la extension **Extension Pack for Java**.
3. Instalar un JDK y verificar que `javac` funcione en la terminal.
4. Compilar:

```powershell
javac *.java
```

5. Ejecutar:

```powershell
java Login
```

Tambien puedes usar las tareas de VS Code:

- `Terminal > Run Task > Compilar Java`
- `Terminal > Run Task > Ejecutar Login`

Usuarios iniciales:

- `admin / 123`
- `asesor / 123`
- `mecanico / 123`
